# Withdrawn raw shutdown exports

The original exports were withdrawn because they included personal contact information, real cluster endpoints, cloud identities, resource names and detailed network inventory. The original filenames remain as withdrawal notices so old documentation links still resolve.

These notices are not evidence of a new command run. The historical shutdown result, timings, known residual resources and limitations remain in [the shutdown worklog](../shutdown.md).

Textual cloud identifiers elsewhere in this repository have been replaced with example values. Screenshots are historical illustrations and have not all been individually redacted. The repository is a record of a retired lab, not deployment configuration for an active environment.
